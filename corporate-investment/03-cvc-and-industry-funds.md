# 03 战略投资、CVC 与产业基金

## 1. 先选参与方式

| 方式 | 控制力 | 资金效率 | 适合场景 |
| --- | --- | --- | --- |
| 少数股权直投 | 中：董事席位、协议权利 | 低：一笔一笔投 | 与主业强相关、需要深度合作的少数标的 |
| 企业风险投资（CVC）：内部团队直投 | 高：与业务部门紧密结合 | 中 | 想系统性跟踪新技术，并能快速转化为业务合作或并购 |
| CVC：独立子公司或专项基金 | 中：在授权范围内自主决策 | 中 | 希望兼顾战略协同和投资速度 |
| 作为 LP 投资外部基金 | 低：不直接决策 | 高：借助专业 GP 覆盖更多项目 | 想获取行业信息流和投资能力，暂不自建团队 |
| 发起或参与产业基金（担任 GP 或主要 LP） | 中到高 | 高：撬动外部资金 | 产业链布局、与地方政府或产业资本合作 |

美国律所 Fenwick 的 CVC 实务指南把 CVC 的组织形式概括为三类：作为外部 VC 基金的单一 LP（最独立）、在授权范围内自主投资的全资子公司、直接为母公司工作并逐笔获得业务部门支持的内部团队（最整合）。见 [Corporate Venture 101](https://www.fenwick.com/insights/publications/corporate-venture-101-considerations-for-starting-corporate-vc-programs)。

## 2. 目标：战略回报和财务回报要先排好序

- **先定可衡量的战略目标**，再平衡财务回报（Fenwick 指南的核心建议）。目标不清，CVC 会在“像财务投资者一样追求回报”和“像业务部门一样追求合作”之间摇摆。
- 常见的战略目标：获取新技术窗口、为业务部门找合作伙伴和客户、为未来并购做储备、了解竞争格局。
- 财务目标：至少不亏损，或达到约定的回报门槛。

| 指标类型 | 例子 |
| --- | --- |
| 战略指标 | 被投企业与业务部门落地的合作数量、引入的技术或产品、转化为并购的项目数 |
| 财务指标 | DPI（已分配回报 / 实缴）、TVPI（总价值 / 实缴）、IRR |

## 3. 治理：自主权、速度与冲突

- **自主权**：明确团队能自主决定的范围（金额、阶段、赛道），超出范围上投决会。创业公司的融资窗口很短，决策流程太长会错过好项目。
- **激励**：团队激励同时挂钩财务回报和战略指标（Fenwick 指南建议）。
- **信息隔离**：被投企业的商业信息不能随意流向与其竞争的业务部门，否则会损害信誉，以后拿不到好项目。
- **对被投企业的价值**：客户资源、渠道、技术支持和更长的投资期限，是 CVC 相对财务投资人的优势，要在谈判中讲清楚并兑现。
- **退出与转化**：提前想好被投企业成长后的路径：继续持有、增持控股、并购，还是财务退出。

## 4. 产业基金：设立前要想清楚的事

1. **基金定位**：财务回报为主，还是战略布局为主？投资范围多大比例必须与主业相关？
2. **出资结构**：企业、政府引导基金、其他产业资本、财务投资人各占多少？各方诉求是否冲突（例如返投比例要求）？
3. **管理人**：自建管理团队，还是委托外部专业 GP？
4. **治理**：投委会构成、关联交易与利益冲突的处理规则、企业作为 LP 是否享有优先投资或优先收购权？
5. **合规**：以私募基金形式运作的，适用《[私募投资基金监督管理条例](https://www.gov.cn/zhengce/zhengceku/202307/content_6890739.htm)》（2023-09-01 施行，对创业投资基金实行差异化监管），管理人登记和基金备案按中国证券投资基金业协会的规定办理。

设立与募集的具体步骤，可参照本仓库的 [基金设立清单](../docs/fund_setup_checklist.md)、[私募募集说明书（PPM）模板](../docs/PPM_template.md)、[合伙协议模板](../docs/partnership_agreement_template.md)，以及 [`scripts/fund_raise_tracker.py`](../scripts/fund_raise_tracker.py)（募集进度跟踪）和 [`scripts/exit_simulation.py`](../scripts/exit_simulation.py)（退出回报模拟）。

## 5. 自查清单

- [ ] 写下了 CVC 或产业基金的三个可衡量战略目标
- [ ] 定好了团队的自主决策范围和投决流程的时限
- [ ] 激励同时挂钩财务和战略指标
- [ ] 有被投企业信息的隔离制度
- [ ] 每个被投项目都有对应的业务部门联系人和合作计划
- [ ] 每年按战略指标和财务指标各复盘一次
