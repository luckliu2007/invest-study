# 尽职调查清单

> 按交易规模和类型取舍；控股并购原则上全覆盖。每一项记录“已核实 / 有问题 / 无法核实”，问题项进入投决会报告第 5 节。

## 1. 业务与商业

- [ ] 市场规模与增速的独立验证（不只看卖方材料）
- [ ] 竞争格局与标的的真实竞争优势
- [ ] 前十大客户收入占比、合同期限、续约率、流失原因
- [ ] 前十大供应商依赖度与替代难度
- [ ] 定价能力：近三年价格变化与毛利率趋势
- [ ] 订单储备与销售漏斗的质量
- [ ] 客户访谈（至少覆盖主要客户和流失客户）

## 2. 财务与税务

- [ ] 收入确认政策与收入质量（一次性收入、关联方收入、期末突击）
- [ ] 经调整的 EBITDA 与各项调整的合理性
- [ ] 营运资金的正常水平与季节性
- [ ] 资本开支：维持性与扩张性分开
- [ ] 净负债与类负债项目（拖欠款、或有对价、员工福利）
- [ ] 税务合规、历史税务争议、潜在补税
- [ ] 预测的可实现性：与历史表现对比

## 3. 法律与合规

- [ ] 股权结构、历史沿革、出资是否到位
- [ ] 重大合同中的控制权变更条款
- [ ] 资质、牌照、许可的有效性与可转让性
- [ ] 知识产权权属（专利、软件著作权、商标、核心代码的权属）
- [ ] 未决诉讼、仲裁、行政处罚
- [ ] 反垄断申报需求（对照经营者集中申报标准）
- [ ] 反商业贿赂与制裁合规（跨境交易尤其重要）

## 4. 技术、数据与网络安全

- [ ] 技术架构、技术债务、与收购方系统的整合难度
- [ ] 核心技术是否依赖少数个人
- [ ] 开源软件使用及许可证合规
- [ ] 数据资产的来源、权属与使用授权
- [ ] 个人信息处理是否合规；是否涉及数据出境
- [ ] 网络安全事件历史、安全管理制度、渗透测试结果
- [ ] AI 相关：使用了哪些模型和数据，是否存在合规或权属风险

## 5. 人员与组织

- [ ] 核心管理层与关键技术、销售人员名单及去留意愿
- [ ] 薪酬、股权激励与控制权变更后的触发条款
- [ ] 劳动合规（社保公积金、劳动争议、竞业限制）
- [ ] 组织文化与收购方的差异

## 6. ESG 与其他

- [ ] 环保合规与潜在环境责任
- [ ] 安全生产
- [ ] 公司治理与关联交易
- [ ] 舆情与声誉风险
