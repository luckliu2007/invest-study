# 01 资本配置与项目评估

## 1. 资本的五个去向

企业手里的每一笔钱，最终只有五个去处。资本配置的本质，就是持续比较这五个去处的回报。

| 去向 | 典型形式 | 什么时候优先 |
| --- | --- | --- |
| 投入现有业务 | 产能扩张、研发、渠道、数字化 | 现有业务的边际回报仍明显高于资本成本 |
| 并购 | 控股收购、资产收购 | 自建太慢，或目标拥有难以复制的能力、客户、牌照 |
| 少数股权与战略投资 | 参股、企业风险投资（CVC）、产业基金 | 需要提前布局新技术、新市场，但还看不清，先买“期权” |
| 偿还债务 | 提前还贷、降低杠杆 | 负债成本高，或需要为周期下行留出安全垫 |
| 回报股东 | 分红、回购 | 找不到回报高于资本成本的机会时，把钱还给股东本身就是正确选择 |

**判断标准只有一个**：投入资本回报率（ROIC）长期高于加权平均资本成本（WACC），才是在创造价值。收入和规模的增长，如果 ROIC 低于 WACC，增长越快，毁灭的价值越多。

## 2. 项目评估方法

| 方法 | 回答什么 | 局限 |
| --- | --- | --- |
| **净现值（NPV）** | 这个项目让公司增加了多少价值 | 依赖现金流预测和折现率，必须配合敏感性分析 |
| 内部收益率（IRR） | 项目的“年化回报率” | 现金流多次变号时可能有多个 IRR；无法比较规模不同的项目；隐含“中途现金按 IRR 再投资”的假设 |
| 静态回收期 | 多久收回本钱 | 不考虑资金时间价值，忽略回收期之后的现金流 |
| 折现回收期 | 考虑时间价值后多久收回 | 仍然忽略回收期之后的现金流 |

**决策以 NPV 为准**，IRR 和回收期作为补充信息。互斥项目选 NPV 最大的，而不是 IRR 最高的。

### 动手：用 `capital_budgeting.py` 评估一个新产品线

```bash
python scripts/capital_budgeting.py
```

示例项目：投资 1,000 万元设备 + 150 万元营运资金，经营 5 年。脚本输出三个情景和敏感性分析：

| 情景 | NPV（10% 折现率） | IRR | 静态回收期 |
| --- | --- | --- | --- |
| 悲观 | −72.5 万元 | 7.75% | 4.33 年 |
| 基准 | 387.0 万元 | 21.33% | 3.18 年 |
| 乐观 | 835.2 万元 | 33.45% | 2.45 年 |

看悲观情景：**静态回收期 4.3 年，看起来能回本，但 NPV 是负的**，因为 IRR 低于 10% 的资本成本。只看回收期就会做错决策。

## 3. 折现率：要匹配项目的风险

- 股权成本常用 CAPM：`无风险利率 + β × 股权风险溢价`，海外项目再考虑国家风险溢价；
- 不同业务风险不同，折现率也应不同：用成熟主业的 WACC 去评估高风险新业务，会系统性地高估新业务；
- β、股权风险溢价、国家风险溢价可以参考 [Damodaran 每年更新的数据](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datacurrent.html)，再结合中国市场的实际情况调整。

## 4. 不确定性怎么处理

1. **情景分析**：至少做悲观、基准、乐观三个情景，并写清每个情景成立的条件。
2. **敏感性分析**：每个关键参数单独上下浮动，找出对 NPV 影响最大的两三个变量，这些变量就是尽调和投后要盯住的重点。
3. **盈亏平衡分析**：销量或利润率降到多少，NPV 归零？离基准有多远？
4. **参考类预测**：找同类项目的历史结果（工期、超支、达产率）校准自己的预测。大型项目普遍存在超支和延期，见 Flyvbjerg《How Big Things Get Done》。
5. **实物期权**：可以分阶段投入、中途可以放弃或扩张的项目，比一次性投入的项目更有价值。设计项目时主动创造“先小步验证、再追加投入”的选择权。

## 5. 常见错误清单

- [ ] 把已经花掉的钱（沉没成本）算进决策
- [ ] 漏算营运资金占用和期末回收
- [ ] 漏算对现有业务的蚕食，或重复计算协同效应
- [ ] 所有项目用同一个折现率
- [ ] 只报 IRR、不报 NPV，或只报基准情景
- [ ] 终值占比过高却不做敏感性分析
- [ ] 预测期的增长率、利润率明显高于行业历史水平，却没有说明理由
